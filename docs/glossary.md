# Glossary

**Mode**: How a game is played: "Two Players" (two people on one computer) or "Vs Computer" (one person against the computer).
_Avoid_: type, setting.

**Move history**: The list of squares played in a game, in order. It's what lets you review a past game or resume an unfinished one.
_Avoid_: log, moves list.

**Forfeit**: A game that ended because a player clicked New Game and confirmed. The player whose turn it was loses. It counts as a completed game.
_Avoid_: quit, abandon, resign.

**Completed game**: A game that ended in a win, draw, or forfeit. Only completed games go in the history and count in totals.
_Avoid_: finished game, past game.
